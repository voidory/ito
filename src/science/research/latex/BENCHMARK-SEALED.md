# Box-selection LaTeX extraction: sealed real papers

Auto-generated by `npm run benchmark:latex:sealed`. Do not edit by hand.

Sealed set: **1579** equations from the source of **30** openly licensed arXiv papers that neither the development corpus nor the held-out set uses, **4590** box selections across 6 tiers. Pages rendered at scale 2 in headless Chromium.

Nobody has read this set's failures and the runner refuses to dump them. It is the only number here that says how the extractor does on papers it was not developed against. Run it at phase gates only: every look, even in aggregate, spends a little of it.

- `real-display`: display equations from the source of 30 openly licensed arXiv papers, set by the benchmark harness (pdfLaTeX, Computer Modern 10pt)
- `real-inline`: inline formulas from the same 30 papers, each inside a line of prose
- `real-inline-punct`: the same inline formulas, each with a comma, full stop, semicolon or colon set against it and inside the box
- `real-display-numbered`: the same display equations, centred and numbered as `equation` sets them, with a box as wide as the text column
- `real-display-dvips`: the same display equations by the older route (latex, dvips, Ghostscript), which draws rules as image masks
- `real-display-lm`: the same display equations in Latin Modern (lmodern with T1 text), less any with a glyph Latin Modern lacks

The interval resamples whole papers (4,000 draws, fixed seed): equations from one paper share its notation and fail together, so an interval that treats equations as independent is too narrow. *Development rate* is the same tier of the development corpus, from `BENCHMARK.json`; the extractor's rules were written against those papers' failures, and against the held-out papers' since the sealed set was made.
